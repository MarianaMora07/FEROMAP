## 4. Guía de preguntas por bloque temático

### Bloque C — Proceso actual de planificación de rutas *(núcleo del diagnóstico)*

| N.º | Pregunta | Respuesta / notas del entrevistador |
|:---:|---|---|
| C1 | Describa **paso a paso** cómo se planifica una jornada de recolección hoy. | |
| C2 | ¿Con cuánta anticipación se definen las rutas? (mismo día, día anterior, semanal) | |
| C3 | ¿Cuánto tiempo le toma a usted (o al planificador) preparar las rutas de un día? | |

| C6 | ¿Qué **criterios** usa para decidir el orden de las paradas? | |
| C7 | ¿Cómo asigna cada camión y conductor a una ruta específica? | |
| C8 | ¿Divide la zona en sectores, rutas o micro-rutas? ¿Cómo los denomina? | |
| C9 | ¿Existe un punto de partida y retorno fijo (base, vertedero, relleno sanitario)? | |
| C10 | ¿Quién valida que la ruta planificada sea viable antes de enviarla a campo? | |
| C11 | ¿Cómo se comunica la ruta al conductor? (hoja impresa, mensaje, verbal, otro) | |

## 5. Preguntas de profundización (usar según las respuestas)

Estas preguntas no se hacen a todos los entrevistados; sirven para profundizar cuando una respuesta sea vaga o requiera mayor detalle.

| Situación detectada | Pregunta de profundización |
|---|---|
| Menciona planificación "a ojo" o por experiencia | ¿Podría describir un ejemplo concreto de la última jornada que planificó? |
| Dice que usan Excel o papel | ¿Qué columnas o datos anotan? ¿Quién llena esa información? |
| Habla de sectores sin definir límites | ¿Cómo decide usted dónde termina un sector y empieza otro? |
| Menciona quejas ciudadanas | ¿Por qué canal llegan las quejas? ¿Influyen directamente en el orden del recorrido? |
| Indica que no hay registros | ¿Cómo justifican ante la jefatura el trabajo realizado cada día? |
| Habla de tráfico pero no lo planifica | ¿Ha notado si ciertas calles son más lentas a determinadas horas? |
| Menciona vertedero o relleno sanitario | ¿A qué distancia aproximada queda del área de recolección? ¿Hay colas de espera? |
| Dice que las rutas son fijas | ¿Cuándo fue la última vez que revisaron o actualizaron esas rutas? |
| Reporta averías frecuentes | ¿Cuántos días al mes pierden camiones por mantenimiento? |
| Muestra interés en tecnología | ¿Qué capacitación considera necesaria para que el equipo la use? |
